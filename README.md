## 🏥 **NGO Use-Case Application**

### Family sharing (private invitation only)

The home page includes an explicit family-data consent flow. The page only
connects to the check-in API when opened using the invitation URL generated by
the signed-in Flutter admin app. A consenting member shares the browser/device
report, connection IP, and live GPS; active location updates stop when the page
closes. Camera and microphone remain separate, user-started actions, with a
separate upload confirmation. The page explains these uses before consent and
provides an option to stop sharing and delete the submitted record.

The invitation link includes the HTTPS API URL and private invitation token in
its URL fragment. Do not post or publicly distribute it. The static GitHub Pages
site alone does not host the API; configure the API deployment's
`PUBLIC_API_URL`, `FAMILY_WEBSITE_URL`, and `WEB_ORIGINS` settings before
generating links in the Flutter app.

### **Problem Statement:**
Healthcare NGOs face challenges in:
- Managing volunteer registrations efficiently
- Providing 24/7 patient support
- Handling large volumes of medical queries
- Ensuring timely responses to emergencies

### **How This App Helps NGOs:**

#### **1. Volunteer Management**
- **Automated Registration** - Streamlines volunteer onboarding
- **AI-Powered Matching** - Suggests optimal roles based on skills
- **Data Organization** - Centralized volunteer database

#### **2. Patient Support System**
- **24/7 Availability** - AI chatbot provides round-the-clock assistance
- **Triage System** - Prioritizes queries based on urgency
- **Resource Guidance** - Directs patients to appropriate services

#### **3. Operational Efficiency**
- **Reduced Response Time** - Instant AI responses for common queries
- **Staff Workload Reduction** - Automates repetitive tasks
- **Data-Driven Insights** - Tracks query patterns and volunteer data

#### **4. Scalability**
- **Cost-Effective** - Reduces need for large support teams
- **Easy Deployment** - Web-based, accessible from anywhere
- **Customizable** - Can be adapted for different healthcare domains

### **Real-World Impact:**
- **Rural Healthcare** - Provides medical guidance in remote areas
- **Crisis Support** - Emergency response during health crises
- **Community Health** - Promotes preventive healthcare awareness
- **Resource Optimization** - Better utilization of volunteer resources

## 🏃‍♂️ **Getting Started**

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/healthcare-support-app.git

# Navigate to project
cd healthcare-support-app

# Install dependencies
npm install

# Start development server
npm start
```

 ### How to Use

- Home Page → Overview & statistics
- Register → Volunteer form
- Contact → Submit support queries
- AI Assistant → Chatbot interaction
- Health Tips → Wellness tips
